SWETHA M - REACT PORTFOLIO

1. Install Node.js.
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev
4. Open the local URL shown by Vite.

IMPORTANT:
- Put your resume PDF in the public folder with this exact name:
  SwethaM_Resume.pdf
- Replace the GitHub and LinkedIn placeholder URLs in src/App.jsx with your actual profile URLs.
- Replace the Naukri URL with your profile URL if desired.

This portfolio uses React + Vite + CSS + Lucide icons.
